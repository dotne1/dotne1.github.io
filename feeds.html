CVE-2026-137888

Published: 2026-11-27 05:17:06 CDT

Severity: N/A

CVSS Score: N/A

Flowintel contains a Server-Side Request Forgery (SSRF) vulnerability in its HedgeDoc case-notes integration. When a user with editor or administrator privileges associates a HedgeDoc URL with a case, the application later issues a server-side HTTP GET request to that URL to retrieve note content. Before the fix, the stored URL was used directly without validation of its scheme, host, port, path, or userinfo, and the HTTP client followed redirects by default with no connect or read timeouts. An authenticated attacker could therefore cause the Flowintel server to issue requests to arbitrary internal or external endpoints (for example, cloud instance-metadata services, internal management interfaces, or other intranet hosts) and receive the response body, or follow a redirect chain to an unintended destination. The absence of timeouts also permitted resource-exhaustion against the server's outbound connection pool. Preconditions: - An authenticated account with editor or administrator role on the target case. - The HedgeDoc integration feature is enabled (no explicit configuration gate existed before the fix). Impact: - Disclosure of sensitive data served by internal or cloud-metadata endpoints. - Potential denial of service through unbounded outbound requests. Affected versions: Flowintel prior to 4.1.0.

CVE-2026-137826

Published: 2026-11-27 05:17:06 CDT

Severity: N/A

CVSS Score: N/A

Lookyloo is a web-based malware analysis and sandboxing platform. The pull-from-remote-instance feature allows a user to request a previously captured sample from another Lookyloo instance by specifying the target instance's URL and a capture UUID. Prior to the fix, the only restriction on the target URL was a check that the hostname, if it was a literal IP address, was not in a private range. Hostnames that resolved to private or internal addresses were not blocked, and no authentication or allowlist was enforced for anonymous users. This allowed any unauthenticated user to direct the Lookyloo server to issue HTTP requests (HEAD to the root path and GET to /json//status, followed by a capture download) to arbitrary internal or external hosts, effectively enabling a Server-Side Request Forgery (SSRF) attack. An attacker could use this to probe internal network topology, access captures stored on internal Lookyloo instances, or leverage the server as a proxy to reach otherwise unreachable services. The vulnerability is in the website/web/__init__.py module, specifically the __get_remote_capture function and the associated pull endpoint. The security impact is unauthorized disclosure of capture data and internal service information from Lookyloo instances that are not intended to be publicly accessible.

CVE-2026-137686

Published: 2026-11-27 04:17:28 CDT

Severity: N/A

CVSS Score: N/A

The fix for CVE-2014-0074 https://shiro.apache.org/security-reports.html#cve_2014_0074 was incomplete for ActiveDirectoryRealm, which still accepted an empty username and password as an anonymous LDAP bind. This allowed an unauthenticated user to log in with an empty principal. This issue affects all Apache Shiro versions through 3.0.1, only when ActiveDirectoryRealm is used without principalSuffix and the directory server allows anonymous binds. Mitigation: Upgrade to version 3.0.2 or later, which fixes the issue. Alternatively, set principalSuffix on the realm, or disable anonymous binds on the directory server.
