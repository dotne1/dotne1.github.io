CVE-2026-128979

Published: 2026-11-23 04:17:15 CDT

Severity: N/A

CVSS Score: N/A

Improper certificate validation vulnerability in Estonian Information System Authority (RIA) libdigidocpp, Estonian Information System Authority (RIA) DigiDoc4, Estonian Information System Authority (RIA) DigiDoc on Android, and Estonian Information System Authority (RIA) DigiDoc on iOS. The vulnerability occurs because libdigidocpp does not properly validate the Extended Key Usage (EKU) extension of certificates used to sign OCSP responses. Specifically, it fails to verify that the certificate contains the id-kp-OCSPSigning EKU, which identifies certificates authorised to sign OCSP responses.  This issue affects libdigidocpp: from 3.10.0 before 4.5.2; DigiDoc4: from 4.0.0 before 4.11.2; DigiDoc: from 3.0.0 before 3.2.0; DigiDoc: from 3.0.1 before 3.2.0.
