CVE-2026-61513

Published: 2026-11-24 15:18:31 CDT

Severity: HIGH

CVSS Score: 7.0

VeraCrypt through 1.26.31 on Linux contains an improper path restriction vulnerability in the elevated CoreService, which passes the path and owner UID from a SetFileOwnerRequest directly to chown() in CoreUnix::SetFileOwner without target validation on Linux. An attacker with an active elevated CoreService session and same-UID access who reopens the request pipe through /proc//fd/ can take ownership of arbitrary system files such as /etc/passwd and /etc/shadow, achieving full root compromise.

CVE-2026-61512

Published: 2026-11-24 15:18:31 CDT

Severity: HIGH

CVSS Score: 7.0

VeraCrypt before 1.26.30 on Linux contains a command injection vulnerability in CoreUnix::CheckFilesystem that allows a local attacker with same-UID access and an active elevated CoreService session to execute arbitrary commands by injecting an unsanitized VirtualDevice value into a shell command string. Attackers can reopen the request pipe through /proc//fd/ and supply a crafted VirtualDevice value such as /dev/null; to achieve arbitrary command execution as root.
