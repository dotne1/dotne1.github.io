CVE-2026-137911

Published: 2026-11-27 07:17:26 CDT

Severity: MEDIUM

CVSS Score: 5.3

FFmpeg before 9.1 contains an out-of-bounds read vulnerability in xwd_encode_frame() in libavcodec/xwdenc.c that copies each RGB24 or BGR24 row using the padded XWD scanline size instead of the pixel row size. Attackers who control the width of video encoded to XWD by an application that supplies tightly packed frames can make the encoder read past the frame buffer, crashing the application or leaking heap contents into the output image.

CVE-2026-137910

Severity: MEDIUM

CVSS Score: 5.3

FFmpeg before 9.1 contains an out-of-bounds read vulnerability in pcx_encode_frame() in libavcodec/pcxenc.c that rounds each row up to an even number of bytes and run-length encodes that many bytes from the input frame. CVE-2026-137907

CVSS Score: 7.8
