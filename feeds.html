CVE-2026-59442

Published: 2026-11-23 05:17:00 CDT

Severity: HIGH

CVSS Score: 7.5

TypesenseFilterExpressionConverter does not correctly translate grouped (parenthesized) filter expressions into the Typesense filter syntax. As a result, the filter sent to Typesense can have a different meaning than the one the application defined, and some conditions may not be applied as intended. An application is affected if it uses the Typesense vector store with filter expressions that contain groups and relies on them to restrict results, for example to enforce tenant isolation or access control. In that case, a remote user may be able to retrieve documents they should not have access to, and the same filter used for a delete operation may remove documents outside the intended scope.

CVE-2026-59340

Published: 2026-11-23 05:17:00 CDT

Severity: MEDIUM

CVSS Score: 6.5

PagePdfDocumentReader and ParagraphPdfDocumentReader are vulnerable to a denial of service when processing untrusted PDF input. The underlying text extraction logic reconstructs layout from a PDF's glyph positions and limits how much memory can be allocated for any single computed gap, but does not limit the cumulative allocation across an entire page. A specially crafted PDF can exploit this to force excessive memory allocation during processing, resulting in OutOfMemoryError. Depending on JVM configuration, this can cause request failures with degraded service under repeated exploitation, or immediate JVM termination when ExitOnOutOfMemoryError options are used. Any application that processes PDFs from untrusted sources (document upload, email attachment processing, RAG ingestion, web crawling) using either affected reader is impacted.

CVE-2026-133646

Published: 2026-11-23 05:16:59 CDT

Severity: N/A

CVSS Score: N/A

Synchronet BBS, in versions 3.20b to 3.21e, contains an out-of-bounds write vulnerability in the answer() function when processing the terminal attribute of the SSH service. The call to cryptGetAttributeString() does not limit the copy to the size of the destination buffer, of which 41 bytes are used. An unauthenticated remote client can send a TERM value of up to 64 bytes and overwrite adjacent fields of the session object. If the SSH service is enabled, this tampering can cause connection threads to be blocked for an extended period, even after the client has disconnected. By exhausting the available sockets, the attacker can prevent new connections and cause a denial of service requiring the software to be restarted.

CVE-2026-123886

Published: 2026-11-23 05:16:58 CDT

Severity: HIGH

CVSS Score: 8.8

Spring Data Elasticsearch replaces positional placeholders in string-based @Query methods with the method arguments before it evaluates SpEL expressions in the resulting query string. As a result, an argument that contains a SpEL expression is evaluated as part of the query, even if the declared query does not use SpEL. An application is affected if it passes untrusted input as an argument to a repository query method that declares a @Query with positional placeholders. In that case, a remote attacker can execute arbitrary code in the application, and repeated requests can exhaust memory through the unbounded expression cache.
