CVE-2026-137941

Published: 2026-11-27 15:17:14 CDT

Severity: HIGH

CVSS Score: 7.8

A flaw was found in GIMP. The Levels configuration setter does not validate the channel enum before using it to index fixed-size per-channel arrays. A crafted XCF file with a non-destructive Levels filter can set an out-of-range channel (LUMINANCE or RGB), causing a heap out-of-bounds read and write when the file is opened. This may lead to a crash or arbitrary code execution.

CVE-2026-137898

Published: 2026-11-27 14:18:17 CDT

Severity: HIGH

CVSS Score: 7.3

A flaw was found in pam. When built with libeconf and an unconfigured vendor directory, the pam_econf configuration handler misinterprets the search path, causing it to look for configuration files in a relative directory within the current working directory. A local attacker can exploit this by placing crafted environment configuration files in a world-writable location. If an administrator executes a privileged command from that directory, the malicious variables are loaded into the privileged process, resulting in local privilege escalation.
