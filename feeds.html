CVE-2026-136703

Published: 2026-11-25 07:17:29 CDT

Severity: MEDIUM

CVSS Score: 4.3

A flaw was found in the Admin REST API v2 of Keycloak. This component is used by administrators to manage realm configurations, including clients. The issue occurs because the API processes a client update (PUT) request and performs payload validation before verifying if the caller has the required permissions to view or manage that specific client. By sending a request with a mismatched client ID in the body, an authenticated user without any administrative privileges can distinguish between existing and non-existing clients based on whether the server returns a 400 Bad Request or a 403 Forbidden error.
