CVE-2026-93584

Published: 2026-11-23 03:17:08 CDT

Severity: HIGH

CVSS Score: 8.6

An SQL injection vulnerability in OTRS versions 2024.3.1 through 2026.8.1 allows unauthenticated remote attackers to inject arbitrary SQL expressions through the Survey endpoint. The vulnerability exists in the Kernel::System::Survey::Request::RequestGet() method, which directly incorporates an attacker-controlled survey key into a SQL query without using parameterized statements. Successful exploitation allows attackers to retrieve ticket information and perform boolean-based or time-based blind SQL injection to extract potentially sensitive data accessible to the OTRS database account. Exploitation does not require authentication, a valid survey key, or an existing survey request. The external frontend must be accessible.
