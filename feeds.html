CVE-2026-136152

Published: 2026-11-24 08:18:17 CDT

Severity: MEDIUM

CVSS Score: 5.3

Prevent Direct Access – Protect WordPress Files plugin before 2.8.9.2 contains an information disclosure vulnerability that allows unauthenticated attackers to obtain protected file names and paths by requesting the dynamically generated robots.txt file, which appends Disallow rules containing attachment page URLs and direct _pda/ directory file paths for all protected media. Attackers can send an unauthenticated HTTP request to robots.txt to enumerate original file names, upload directory structures, and attachment slugs, undermining the plugin's file protection and potentially enabling direct file access if server-level restrictions are misconfigured or absent.
