CVE-2026-137435

Published: 2026-11-26 06:17:13 CDT

Severity: N/A

CVSS Score: N/A

A flaw was found in the SAML identity brokering component of Keycloak. When Keycloak is configured to use a database with case-insensitive collation, it may incorrectly match a SAML subject name to an existing user account if the names differ only by case. This issue allows an attacker to log in as a different user by providing a case-distinct version of a victim's username in a signed SAML assertion, leading to unauthorized account access.

CVE-2026-137431

Published: 2026-11-26 06:17:13 CDT

Severity: MEDIUM

CVSS Score: 4.2

A flaw was found in the keycloak-services component of Keycloak, which is used to handle OpenID Connect authentication flows. The issue occurs because the security check that prevents attackers from pre-seeding security parameters in a redirect URL can be bypassed by adding an extra question mark character to the parameter name. This allows an attacker to trick a user's browser into using an attacker-controlled login code. As a result, a victim may be unknowingly logged into an attacker's account, leading to account confusion or the exposure of sensitive data entered by the victim.
