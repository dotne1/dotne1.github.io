Severity: MEDIUM

CVSS Score: 4.9

CVE-2026-114732

Published: 2026-10-21 22:16:38 CDT

Severity: MEDIUM

CVSS Score: 6.8

Roundcube Webmail before 1.6.20 and 1.7.x before 1.7.5 is affected by an improper authentication vulnerability in multi-host installations. When a user logs in with an alias address, rcube_user::query() matched the address against identity records without qualifying the lookup by IMAP host, so a login could be resolved to a user account belonging to a different IMAP host. Upstream fixed this in the commit “Fix bug where an alias login wasn’t qualified by IMAP host”.
