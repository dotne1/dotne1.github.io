CVE-2026-137686

Published: 2026-11-27 04:17:28 CDT

Severity: N/A

CVSS Score: N/A

The fix for CVE-2014-0074 https://shiro.apache.org/security-reports.html#cve_2014_0074 was incomplete for ActiveDirectoryRealm, which still accepted an empty username and password as an anonymous LDAP bind. This allowed an unauthenticated user to log in with an empty principal. This issue affects all Apache Shiro versions through 3.0.1, only when ActiveDirectoryRealm is used without principalSuffix and the directory server allows anonymous binds. Mitigation: Upgrade to version 3.0.2 or later, which fixes the issue. Alternatively, set principalSuffix on the realm, or disable anonymous binds on the directory server.

CVE-2026-112189

Published: 2026-11-27 04:17:26 CDT

Severity: N/A

CVSS Score: N/A

A path traversal vulnerability in Medusa’s product import functionality, specifically in the handling of the 'file_key' parameter of the '/admin/products/imports' endpoint. The lack of proper validation allows an authenticated remote attacker with administrative access to reference system files outside the intended import directory. When attempting to process these files as CSV files, the application may partially reveal their contents through parsing or validation error messages. Additionally, cleanup routines operate on paths controlled by the attacker, which could allow the deletion of files accessible to the application process and affect system availability.
