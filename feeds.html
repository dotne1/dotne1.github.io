CVE-2026-93010

Published: 2026-10-29 09:18:00 CDT

Severity: MEDIUM

CVSS Score: 4.3

A flaw was found in dnsmasq. When DHCP leasequery is enabled without listing allowed source addresses, the server does not check who sent the query. A host on the local network can request DHCP lease records and learn assigned addresses, MAC addresses, hostnames, and related lease metadata. The feature is off unless an administrator turns it on.

CVE-2026-93009

Published: 2026-10-29 09:18:00 CDT

Severity: MEDIUM

CVSS Score: 4.3

A flaw was found in dnsmasq. The DHCPv6 client hostname parser can read one byte past the end of a crafted FQDN option because it checks the next label length before confirming the pointer is still inside the option. An attacker on the local network can trigger this with a single DHCPv6 packet. The extra byte is not returned to the client or logged, and no crash has been demonstrated.
