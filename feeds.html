CVE-2026-136442

Published: 2026-11-24 13:18:20 CDT

Severity: MEDIUM

CVSS Score: 6.5

BusyBox ftpd Directory Traversal Arbitrary File Read and Write Vulnerability. This vulnerability allows remote attackers to create or delete arbitrary files or disclose sensitive information on affected installations of BusyBox. Authentication is not required to exploit this vulnerability. The specific flaw exists within the ftpd service, which listens on TCP port 21 by default. The issue results from the lack of proper validation of a user-supplied path prior to using it in file operations. An attacker can leverage this vulnerability to create or delete files or disclose information in the context of the service account. Was ZDI-CAN-27555.
