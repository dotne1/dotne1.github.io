CVE-2026-5771

Published: 2026-11-28 06:17:42 CDT

Severity: MEDIUM

CVSS Score: 4.3

The Loco Translate plugin for WordPress is vulnerable to Arbitrary File Write/Overwrite via Path Traversal in all versions up to, and including, 2.8.4. This is due to the normalize() function processing '..' segments in user-supplied paths without verifying that the resolved absolute path remains within the base directory. This makes it possible for authenticated attackers, with Custom+ level access and above, to write translation files to arbitrary locations on the filesystem.
