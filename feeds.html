CVE-2026-118898

Published: 2026-11-24 23:18:27 CDT

Severity: N/A

CVSS Score: N/A

Deserialization of Untrusted Data vulnerability in lasp-lang partisan allows an unauthenticated remote attacker to abort the Erlang VM of a node via Excessive Allocation. partisan_peer_service_server:handle_info/2 decodes every frame that arrives on the peer listener with binary_to_term/1, without the safe option, before handle_inbound/2 interprets the message and before any peer authentication takes place. TLS is off by default and the listener accepts connections from any host, so one frame that names more atoms than the atom table holds aborts the VM. partisan_peer_service_client:handle_info/2 decodes frames from the server side of a connection the same way. The decode also materializes funs, ports and references the frame encodes and inflates compressed terms. The demonstrated impact is denial of service. partisan does not invoke decoded funs, so code execution was not shown. This issue affects partisan: from 3.0.0 before 6.4.0.
