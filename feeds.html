CVE-2026-129984

Published: 2026-11-24 12:19:02 CDT

Severity: MEDIUM

CVSS Score: 4.3

AutoGPT is a workflow automation platform for creating, deploying, and managing continuous artificial intelligence agents. In versions 0.6.67 to 0.11.2, organization and team billing-manager roles intended only for spend management are treated as ordinary members across workflow, run, library, and marketplace routes. Although the role matrix in autogpt_platform/autogpt_libs/autogpt_libs/auth/permissions.py withholds run access and workflow creation, those routes do not enforce the matrix and their underlying membership lookups ignore the caller's role. As a result, a team billing manager can read team workflows and other members' runs (including inputs, outputs, and per-node data), while an organization billing manager can view shared workflows and runs and create workflows and marketplace listings; neither can modify or delete other members' workflows. This issue is fixed in version 0.11.3.

CVE-2026-129425

Published: 2026-11-24 12:19:02 CDT

Severity: N/A

CVSS Score: N/A

Joomla Extension - regularlabs.com - PHP code injection via content inserted during article preparation in Sourcerer extension < 17.0.2 - Sourcerer decided whether PHP may run based on the author or last editor of the host article and applied that decision to complete code blocks that other extensions, such as Users Anywhere or Articles Anywhere, inserted into the article while it was prepared. A user able to edit a value rendered by such an extension, for example the display name in their own user profile, could therefore have PHP executed in the context of a trusted article. Sourcerer 17.0.2 authorizes each executable block against its own source; Users Anywhere 3.1.0, ReReplacer 16.4.0 and Snippets 11.2.0 supply the source information needed to keep executing eligible saved content.
