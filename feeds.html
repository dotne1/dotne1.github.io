CVE-2026-129483

Published: 2026-11-15 08:17:27 CDT

Severity: CRITICAL

CVSS Score: 9.1

Cyrus SASL through 2.1.28 contains an authentication bypass vulnerability in the SRP server mechanism because srp_server_mech_step2 does not reject client public values A that are multiples of N. Unauthenticated network clients can send A equal to N to force a zero shared secret, authenticating as any existing user without the password and learning session keys.

CVE-2026-129482

Published: 2026-11-15 08:17:27 CDT

Severity: MEDIUM

CVSS Score: 4.8

OkHttp through 5.5.1 contains an improper certificate validation vulnerability in CertificatePinner that skips pin checks because Pin.matchesHostname does not normalize trailing-dot hostnames. Network attackers with a CA-trusted certificate not matching configured pins can intercept or modify TLS traffic when applications request the trailing-dot form of pinned hosts.

CVE-2026-129480

Published: 2026-11-15 08:17:27 CDT

Severity: MEDIUM

CVSS Score: 5.3

Assimp through 6.0.6 contains a heap out-of-bounds read vulnerability in MD2Importer::InternReadFile that allows attackers to read past the file buffer via an unvalidated stored frameSize header field.
