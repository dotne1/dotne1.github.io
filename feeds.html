CVE-2026-115232

Published: 2026-11-23 02:17:13 CDT

Severity: N/A

CVSS Score: N/A

In iceoryx2 versions from 0.6.0 to 0.10.0, The C API getters that copy a service's hash into a caller-provided buffer (e.g. iox2_port_factory_pub_sub_service_hash and its other messaging protocol counterparts) write one byte past the end of the caller's buffer when `buffer_len` is less or equal to 40. The out-of-bounds byte is the string's NUL terminator, written at `buffer[buffer_len]`. Resolution: Resolution The bugfix is released with iceoryx2 version 0.10.1 and on main branch (commit 7ca14dd). Please note that the language bindings for C/C++ and Python (including the iceoryx2-ffi-c crate) are not published to crates.io since they are a local development dependency.
