Ledger — Penetration Test Disclosure Report

TryHackMe Hard · 2026-07-17

Target: 10.67.171.16 (labyrinth.thm.local) Assessment Date: 2026-07-17 Classification: CONFIDENTIAL (lab / THM)

1. Executive Summary

This assessment targeted a Windows Server 2019 domain controller for thm.local. Unauthenticated LDAP allowed full user enumeration and disclosure of weak password patterns in account descriptions. Password spraying recovered domain credentials for SUSANNA_MCKNIGHT. Active Directory Certificate Services (AD CS) was misconfigured: the ServerAuth template permitted ESC1 (enrollee-supplied subject with client authentication, enrollable by Authenticated Users). Certificate-based impersonation of Domain Admin BRADLEY_ORTIZ yielded full administrative control of the domain controller and both user and root flags.

5. Findings Detail

F-01 — AD CS ESC1 (ServerAuth)

Severity: Critical (CVSSv3: 9.8) Vector: AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H (effective Critical when chained from low-priv user; network reachable enrollment)

Description: Template ServerAuth on CA thm-LABYRINTH-CA allows Authenticated Users to enroll, sets Enrollee Supplies Subject, and includes Client Authentication EKU. Any domain user can request a certificate for an arbitrary UPN (e.g. Domain Admin) and authenticate via PKINIT to obtain a TGT and NT hash.

Evidence:

certipy-ad find ... -vulnerable  → ESC1 on ServerAuth
certipy-ad req ... -template ServerAuth -upn 'BRADLEY_ORTIZ@thm.local'
certipy-ad auth -pfx bradley_ortiz.pfx
→ NT: 16ec31963c93240962b7e60fd97b495d

Impact: Domain Admin / DC compromise without knowing the DA password.

Remediation: Remove enrollee-supplied SAN on authentication templates; restrict Enroll to tightly controlled groups; enable manager approval for sensitive templates; monitor certificate requests for unexpected UPNs/SIDs.

F-02 — Weak / predictable passwords and description leakage

Severity: High (CVSSv3: 8.8) Vector: AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H (when combined with null LDAP read of descriptions and successful spray)

Description: LDAP user objects exposed description text of the form Please change it: CHANGEME2023!. Spraying that password across the domain succeeded for SUSANNA_MCKNIGHT, providing authenticated foothold used for AD CS abuse.

Remediation: Never store passwords in AD attributes; enforce unique strong passwords and change-on-first-logon; block password spraying with lockout/smart lockout; remove description secrets and audit with scripts.

F-03 — Anonymous LDAP bind and SMB null/guest session

Severity: Medium (CVSSv3: 5.3) Vector: AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:N/A:N

Description: Unauthenticated clients could bind to LDAP and list users, groups, and descriptions. SMB null/guest sessions negotiated successfully (limited share access).

Remediation: Disable anonymous LDAP binds and Pre-Windows 2000 Compatible Access where possible; disable Guest; restrict null sessions; require signing and proper ACLs on sensitive containers.

8. Recommendations (priority)

  1. Fix or remove the ServerAuth ESC1 misconfiguration immediately.
  2. Rotate all accounts that used CHANGEME2023! and purge secrets from AD attributes.
  3. Harden anonymous LDAP/SMB.
  4. Deploy AD CS monitoring (e.g. abnormal certificate requests, ESC detection tooling).
  5. Prefer gMSA/managed identities for service accounts; least-privilege enroll rights.

9. Cleanup

No persistent implants, scheduled tasks, or reverse shells were left on the target. Certificate requests issued during testing (IDs ~25–26) remain in the CA database as normal enrollment artifacts; revoke if required by lab policy. Local loot retained only under the engagement folder.
