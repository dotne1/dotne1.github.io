Billing — Penetration Test Disclosure Report

TryHackMe Easy · 2026-07-17

Target: 10.66.143.171 Assessment Date: 2026-07-17 Classification: Lab / CTF

1. Executive Summary

The Billing host runs MagnusBilling on Apache. An unauthenticated command injection (CVE-2023-30258) in the Icepay library yielded a shell as asterisk. That account could run fail2ban-client via passwordless sudo; abusing ban actions produced a root shell and full compromise.

5. Findings Detail

F1 — Unauthenticated command injection in Icepay endpoint

Severity: Critical (CVSSv3: 9.8) Vector: AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H

GET /mbilling/lib/icepay/icepay.php?democ=<payload> allows OS command injection after a semicolon. Confirmed with time-based and reverse-shell payloads.

Remediation: Patch MagnusBilling; remove/disable vulnerable Icepay demo path; input validation / disable dangerous PHP functions if unused.

F2 — fail2ban-client sudo without password

Severity: High (CVSSv3: 7.8)

asterisk may run /usr/bin/fail2ban-client as root without a password. Attackers can redefine actionban to run arbitrary commands (e.g. SUID on /bin/bash) and trigger them via banip.

Remediation: Remove NOPASSWD or restrict to non-action-mutating subcommands; harden Fail2Ban configs against runtime action injection.
