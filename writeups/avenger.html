AVenger — Penetration Test Disclosure Report

TryHackMe Medium · 2026-07-17

Target: 10.66.179.138 (gift / avenger.tryhackme) Assessment Date: 2026-07-17 Classification: Lab / CTF

1. Executive Summary

AVenger is a Windows Server 2019 host running XAMPP and WordPress. A Forminator contact form accepts dangerous file types and is processed by an automated reviewer that executes uploaded batch files as a local administrator account under UAC. This yielded user-level code execution and the user flag. Cleartext autologon credentials and a fodhelper-based UAC bypass escalated privileges to read the Administrator desktop root flag. Full compromise of the box was achieved.

5. Findings Detail

F1 — Forminator form executes uploaded batch files

Severity: Critical (CVSSv3: 9.8) Vector: AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H

The WordPress Forminator form (module 1176) on http://avenger.tryhackme/gift/ accepts extensions including .bat, .php, and .exe. Submissions are opened by a backend process that executes batch content as gift\hugo. No authentication is required.

Impact: Unauthenticated remote code execution as a privileged local user (subject to UAC).

Evidence: Successful form POST returned a thank-you message; subsequent HTTP callbacks to the attacker and reverse shell as gift\hugo.

Remediation: Restrict allowed extensions to images/docs only; never auto-open or execute uploads; sandbox review workers; keep Forminator updated.

F2 — Autologon password stored in cleartext

Severity: High (CVSSv3: 7.8) Vector: AV:L/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H 

HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon
  AutoAdminLogon = 1
  DefaultUserName = hugo
  DefaultPassword = SurpriseMF123!

Readable by low-privilege users. Enabled WinRM/RDP as hugo.

Remediation: Disable AutoAdminLogon; remove DefaultPassword; use LAPS or interactive logon only.

F3 — Local admin under UAC filter; fodhelper bypass

Severity: High (CVSSv3: 7.8)

hugo is in BUILTIN\Administrators but runs at Medium integrity (Admin group “deny only”). Fodhelper registry hijack under HKCU\Software\Classes\ms-settings\Shell\Open\command elevates a command without interactive UAC consent in this environment.

Impact: Read Administrator desktop and perform high-integrity actions.

Remediation: Prefer standard users for day-to-day; enable Always Notify UAC; block known UAC bypass binaries via AppLocker/WDAC where possible.
